# 蜗牛待办

一个简单的待办事项应用

## 已有功能

- 查看待办事项
- 添加待办事项
- 标记完成
- 删除待办事项
- 按全部 / 待完成 / 已完成筛选，并显示任务数量
- 设置可选的截止时间
- 对未完成且超时的任务显示过期提醒
- 按截止时间排序，支持从早到晚和从晚到早，无截止时间的任务排在最后
- 一键将所有任务标记为完成
- 清除已完成任务
- 自动保存待办及截止时间，刷新页面后仍保留

## 使用方式

项目文件分工如下：

- `index.html`：页面结构和内容。
- `style.css`：页面样式，如颜色、字体和布局。
- `app.js`：应用功能，如添加、完成、删除待办和本地保存。
- `README.md`：项目说明。

将 `index.html`、`style.css` 和 `app.js` 保留在同一个文件夹中，直接用浏览器打开 `index.html` 即可使用，无需安装依赖。

也可以在项目目录运行 `python3 -m http.server 8000`，然后访问 http://localhost:8000。

支持全部 / 待完成 / 已完成筛选、任务数量统计和清除已完成任务。待办自动保存在当前浏览器的本地存储中；清理浏览器数据会删除这些记录，不同浏览器之间不共享数据。
